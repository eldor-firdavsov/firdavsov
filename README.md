# ELDOR.DEV

Editorial portfolio for Eldor — Frontend Developer → AI/ML Engineer.

Visual language inspired by Pamidor Design (composition, whitespace, typography, Lab, motion) with original content and assets.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Motion
- Vercel-ready

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

Edit data files — do not hard-code projects in JSX:

- `src/data/projects.ts`
- `src/data/experience.ts`
- `src/data/experiments.ts`
- `src/data/socials.ts`

Project visuals live in `public/projects/`.
